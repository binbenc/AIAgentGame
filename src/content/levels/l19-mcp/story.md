Nova 的硬件团队交付了一个 **MCP 服务器**：“Nova 智能家居设备”，能列设备、调温度、查固件。同一周，市场部也想把你的订单工具接进他们的营销助手，数据团队想接进 BI 机器人。

> **Mia（产品经理）**：每个团队都来找你要“集成一下”。三个 Agent、五套工具，就是十五份胶水代码，谁改个参数大家一起炸。

> **老周**：这就是 M×N 问题。**MCP（Model Context Protocol）** 把它变成 M+N：工具方实现一次 MCP 服务器，任何支持 MCP 的 Agent——Claude Desktop、Claude Code、Cursor，还有我们自己的——都能直接接上。底层就是 JSON-RPC 2.0，没什么神秘的。

> **老周**：今天你两头都做：把订单工具包装成一个 MCP 服务器；再写一个 MCP 客户端，让我们的 Agent 同时用上硬件团队的设备服务器和你自己的订单服务器。

> **Vera**：提醒一句：第三方服务器返回的内容、甚至**工具描述本身**，都是不可信输入。别忘了上一关学的东西。
