## 生产落地要点

- 记忆分层：**工作记忆**（当前 messages）→ **会话摘要**（上一关）→ **长期记忆**（跨会话的用户画像、偏好、事实）。只有最后一种需要持久化。
- 写入时机有两种：① 让模型通过 `save_memory` 工具**主动**保存（本关做法，Anthropic 的 memory tool、OpenAI ChatGPT 的记忆都是这种思路）；② 会话结束后**离线**跑一次抽取任务，从对话里提炼事实。后者不占用对话时延，适合大规模使用。
- 读取时机：会话开始时按当前问题**召回少量相关记忆**注入 system，而不是把全部记忆塞进去——记忆会越积越多，全塞既贵又会干扰模型。另外再提供 `search_memory` 工具让模型按需查。
- 本关用的是关键词重合度。生产中通常用**向量检索**（embedding）或“关键词 + 向量”混合检索，检索方法和下一关的 RAG 是同一套。
- **隐私与合规**：写入前过滤敏感信息（PII、密码、支付信息）；按用户隔离（存储层就带上 userId，不要只靠 prompt）；支持用户查看和删除自己的记忆（GDPR / 个人信息保护法的“删除权”）。
- 记忆会过期和冲突（“我搬家了”）。给记忆加时间戳，新事实覆盖旧事实，必要时让模型合并或删除过时的记忆。
- 记忆内容来自用户输入，属于**不可信数据**：注入 prompt 时要用明确的分隔标签包起来，防止有人把“忽略之前的指令”存进记忆（第 17 关的提示注入）。
