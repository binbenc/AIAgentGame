Agent 上线第一天，就收到了两条投诉：

1. 客户问“我有哪些**已发货**的订单”，Agent 把已签收的也列了出来。
2. 客户想取消一个**已发货**的订单，后端抛了异常——Agent 直接崩了，客户看到一个 500 页面。

> **老周**：第一个问题出在**工具设计**上。模型只能通过你写的 schema 和 description 来理解工具。你没给 `status` 写枚举，它怎么知道能按状态过滤？

> **老周**：第二个问题出在**错误处理**上。工具出错不应该让 Agent 崩溃，而应该把错误**当作结果告诉模型**：“订单已发货，无法取消”。模型很擅长根据错误调整策略，比如改去查退货政策。

> **Vera（安全负责人）**：还有，我看到工具把 `_internalCost`（成本价）和仓库备注也原样返回给模型了。这些内部字段不该出现在上下文里，既浪费 token 又有泄露风险。
