> **Mia（产品经理）**：客户觉得我们“不长记性”。每次开新会话，Agent 都把人忘得一干二净。

> **老周**：上下文窗口只是**工作记忆**，会话一结束就清空。要让 Agent 记住人，得有**长期记忆**：对话中发现长期有效的偏好，就存起来；下次会话开始时，把相关的记忆找出来放进 system。

> **Vera（安全负责人）**：先说好，记忆库不是什么都能存的。昨天我看到测试环境里有人让 Agent “记住我的信用卡号”——它真记了。长期记忆会被反复注入 prompt，还会落盘，**密码、卡号、证件号一律不许进去**。还有，A 用户的记忆绝不能出现在 B 用户的对话里。
