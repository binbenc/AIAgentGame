## Production notes

- **Trace using the OpenTelemetry GenAI semantic conventions**: attributes like `gen_ai.request.model`, `gen_ai.usage.input_tokens`, `gen_ai.usage.output_tokens` and `gen_ai.operation.name` are standardized. Langfuse, LangSmith, Arize Phoenix and Datadog LLM Observability all consume them directly — instrument once, use anywhere.
- **Attribute cost by feature**: tag every call with `feature`, `tenant`, `user` and so on. "The bill tripled" is only actionable once you can pin it to a specific feature and customer. Don't forget retries and failed calls — they cost money too.
- **Prompt caching (provider-side)** is different from this level's response cache: Anthropic uses `cache_control` to mark reusable prefixes, with cache reads at about 10% of the normal input price (writes cost slightly more than normal); OpenAI caches long prefixes automatically. For a high hit rate, put **stable content first** (system prompt, tool definitions, long documents), changing content last, and never put timestamps in the system prompt.
- **Response caching** only suits deterministic, user-independent questions (FAQs). Answers involving personal data or live status must never be cached across users. The advanced version is semantic caching (hits by embedding similarity), but beware false hits where similar questions need different answers.
- **Model routing**: small models (e.g. Claude Haiku) for simple questions, large models for complex tasks. Rule-based routing costs nothing; you can also classify with a small model first, or "start small and escalate when confidence is low". Validate any routing strategy with your eval set (Level 16) to make sure quality didn't drop.
- **Watch percentiles, not averages**: p50 is the typical experience; p95/p99 is where complaints come from. Break agent latency down into "model time + tool time + queueing".
- **Budgets are hard limits**: cap each run, each user and the global daily spend; when a cap trips, alert and give the user a graceful fallback. Check the budget **before** the call — finding out after the money is spent is too late.
- **Redact prompts before logging them** (reuse `redactSecrets` from Level 17). If logging everything is too expensive, **sample** — but keep 100% of failed requests.
