## 生产落地要点

- 这个循环就是 Anthropic Tool Runner、OpenAI Agents SDK、LangGraph `create_react_agent` 的内核。理解了它，所有框架都只是在它上面加功能。
- **步数上限是必须的**，最好再加上 token 和费用上限（第 18 关）。达到上限时，要给用户一个体面的降级回复，并上报告警。
- 并行工具调用：模型一次返回多个 `tool_use` 时，要**全部执行**，并把所有 `tool_result` 放进**同一条** user 消息。拆成多条消息会让模型以后越来越少用并行调用。
- `messages` 就是 Agent 的完整状态。只要把它持久化，就能做断点续跑、审计和回放（第 12 关会用到）。
- 先问自己：**这个任务真的需要 Agent 吗？** 流程固定的任务，用写死的工作流更便宜、更可控（第 11 关）。
